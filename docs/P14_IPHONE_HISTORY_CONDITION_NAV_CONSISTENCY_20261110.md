# P14｜iPhone画面整合：GPSカード・探究遷移通知・共通見出し・コンディション／実績（2026-11-10）

## 背景・現行比較
- iPhoneの実画面：履歴下部「GPSで測定した記録」が外側余白＋内側カードとなり、記録一覧と比べて面積が大きい。長い空間はHistory Shadow DOMの `.stage` の `min-height:calc(100vh - 60px)` も寄与。
- 探究→学習の際に一瞬オレンジ色の通知が見える原因：`app.js` の `hashchange` にあるP8の個人情報保護用の退場処理が、新しい行先に関係なく `ex-notice`（茶色／オレンジの汎用警告）で「記録を切り替えています…」を挿入していた。学習への遷移は記録の切替とは異なるため、内容・意味・色が不適切。
- 見出しは画面別CSSで異なる指定（記録1.33rem、ホーム／履歴／学習／設定1.65remなど、狭幅でさらに変更）。コンディションの歩みは青緑系の旧配色だが、ホームのコンディションカードは承認済みの紫／紺色に更新済み。実績カードの「開く」は青緑の共通ボタンに寄っていた。

## 機能設計判断
1. 履歴GPS欄は折りたたみ（P13）を維持したまま、カードを一枚に見えるようにする。GPS V1/V2の記録・結果・補足・削除・バックアップ・容量確認の操作を変えない。
2. P8/I3の遷移時プライバシー封鎖（旧画面を即時 `hidden` ＋ `display:none!important`）は必ず保持。待機通知は探究内の表示変更に限定し、ニュートラルな青緑スタイルと短い文言に変更。学習・他画面への遷移では通知を挿入しない。記録は自動選択しない。
3. 共通の画面見出しサイズを `1.625rem`、行高1.3、太さ900に統一。長いタイトルは320–420px幅で重なりを防ぐ例外を適用し、情報の読みやすさと44pxの戻る／ヘルプ操作を優先する。教材内の学習テーマ見出しは別階層のままにする。
4. コンディションの歩みは、ホームのコンディションカードと同じ紫系にする。保存した生活記録や申告、観察の内容と欠測ルールは維持。気分のカテゴリー色を医学的判定に使わない。
5. コンディションの「開く」は紫カードに対して青緑（操作を識別しやすくする補色系）、実績の「開く」は実績カードと同じ金／茶系のアクセントにする。操作位置・押下イベント・実績集計条件は変更しない。色は医学的／能力的な評価ではない。

## 画面設計判断
- GPSカードは余白、外枠、影、サマリー行の高さを他の履歴カードに近づけ、0件をタイトル右側へ表示。Shadow DOMの高さ指定を解除して表示内容に応じた高さとする。
- 旧 `ui/conditionJourney.css` と `ui/homeExperience.css` の由来を残し、新しい `ui/screenCoherenceP14.css` をP13のCSSの後に追加して範囲を限定して上書き。公式Currentを上書きしない。
- `ui/historyExperience.css` はShadow DOMで利用する `ui/historyInlineStyles.js` と完全一致。モジュール、HTML、service worker生成、PWAキャッシュは `20261110-p14-visual-v3` で更新。教材本文と科学値に変更なし。

## 検証範囲と限界
- P14のNode検証：退場処理の条件、Shadow CSSと埋め込みの一致、カード寸法のCSS、共通見出し、コンディション紫系と2つの「開く」の配色、SW整合。
- P11画面試験：6画面の見出しの実際のフォント寸法、GPS欄の外枠・パディング・サマリー高さ、条件画面の紫系背景、2つの「開く」の配色分離。Chromium/WebKitを用いるが、実機iPhoneの最終目視の代替ではない。
- RQ3の範囲：画面の設計・実装整合と技術成立性を確認する。自己理解の向上や学習効果は検証しない。

## P14.3 320px対応（追加監査）
- 画面名6件は同じ1.625remに統一。ただし長い「手入力で記録」のみ狭い画面では縮小する。
- iPhone 320pxでホーム「編集」の文字が10.72pxになる旧CSSを新しい約13pxに変更。「？」は20pxのアイコンであり編集テキストと文字サイズを同一視しない。44pxのタッチ領域・位置は維持。
- S02ホームガイド試験を文字サイズの等価比較から、アイコンとテキスト各々の可読性と同じタッチ高さを確認する検証へ修正。
