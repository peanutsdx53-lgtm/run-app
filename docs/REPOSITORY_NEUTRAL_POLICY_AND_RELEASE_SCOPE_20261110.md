# リポジトリ移行前・利用規約と公開先リンクの非依存化（2026-11-10）

## 指示と対象
GitHub上でソースコードとWebアプリが公開されても、一般向けの正式リリースは行わない。移行先のリポジトリは未確定なので推測しない。既存リポジトリ `peanutsdx53-lgtm/runload-app-v2` のURLを規約・プライバシーポリシー・現行利用ガイド・デプロイ確認・画像参照コードから除去する。

## 実装と根拠
- 利用規約とプライバシーポリシー：旧IssuesのURL・公開の問い合わせ欄で非公開連絡方法を探す案内を削除。代替連絡先を捏造せず、現時点でアプリ内の窓口が未案内であることを明記。GitHubでの公開と一般向け正式リリースを区別する。
- `LEGAL_VERSION` は 2026-11-10 に改定。連絡方法・公開状態の記述が変わるため、既存の同意内容を新規約への同意と見なさない。保存キーの名称・データ形式は変更しない。
- ROF-Jの図は `assets/rof/` のローカルファイルのみを使用。不要な旧repoへの絶対URL定数とService Workerの旧repo画像専用キャッシュ例外を削除。著者・文献情報や表示ラベル・5図・選択0〜10は維持。
- READMEと利用ガイド：旧clone URL・Pages URL・旧Actions URLを除去。移行先URLは未設定のまま、一般向けリリースではないことを明記。
- 公開サイト受入：`RUNLOAD_PAGES_URL` をGitHub Actionsの変数に設定した場合だけそのURLを確認。未設定ならテストステップはスキップされ、旧repoの公開サイトを誤検査しない。
- `scripts/auditRepositoryBindings.mjs`：Git追跡ファイルを全件走査。実行時コードと現行ガイドで旧owner・旧repoへのリンクが残れば失敗。過去の研究記録・監査資料内の引用は履歴として分類し、原本を改変しない。

## 移行・運用上の留保
- **新しいリポジトリの作成・転送・Pagesの公開先設定・Actions変数の設定は実施していない。**
- GitHub Pagesでブラウザからアクセス可能な状態は、一般向け正式リリースを行わない方針と区別する。公開サイトである以上、第三者がアクセスする可能性は残る。
- 問い合わせ窓口の未設定は、個人情報への対応や適用法令の確認に関する残課題。窓口が決まったら、運営者が適切な案内・法令対応を確認して文書を改定する必要がある。
- リポジトリ・Pagesのオリジンが変わると、ブラウザのLocal Storage・IndexedDB・Service Workerの保存領域も分かれる。既存記録は自動移行されない。移行作業に伴うデータの無断変更・削除はしない。
- 特定コミットのCI成功は実機確認、法的審査、一般向けリリースを意味しない。
