# RunLoad v2｜英語表示プレビュー実装・検証記録（2026-11-11）

## 1. 対象・完了範囲
日本語版を正式な基準実装として維持し、設定から明示的に選択した場合のみ **English (preview)** を表示する。初回案内の言語選択は現時点では日本語固定のままにする。これは法的同意文書の正式な英語版が未完成であり、同意や理解を英訳済みと誤認させないための境界である。

**今回「英語版完全公開」の認定は行わない。** 主要メニュー、設定、記録・結果・履歴・探究の代表的UIラベル、参考値の見出し等の明示的にレビューした辞書の文言のみ英語化する。長文の注意・研究文献・エラーメッセージ・利用規約・プライバシーポリシー・印刷/PNG/PDF/共有出力・GPSの全通知・全20画面の全状態には未翻訳文言が残る。

## 2. 実装・機能設計根拠
- `ui/settingsExperience.js`：既存DISPLAY_KEYの保存形式に後方互換な `language: 'ja' | 'en'` を追加。未設定はja。破損・不正キーの設定は部分適用せず、日本語の既定表示へフォールバック。保存時は既存CAS比較を維持し、別タブによる新しい変更を古い設定で上書きしない。保存レコード、科学エンジン、GPS軌跡、後日追記、同意は変更しない。
- `ui/englishUi.js`：定義済みの短いUI語句のみを厳密一致で翻訳。ネットワーク翻訳は利用せず、PWAでオフライン起動可能。Shadow DOMを含め、画面の再描画や追加DOMに追従。未知の文言を憶測で翻訳しない。
- `app.js`：言語変更イベントを既存の表示設定と一体化。 `render()` で画面だけ再構築する。保存元データは書き換えない。
- `ui/firstUseExperience.js`：公式日本語の利用規約・プライバシー本文は `lang="ja"` として保持。翻訳処理から法的文書領域を除外し、**英語版規約と誤認させない**。
- `index.html` / `sw.js`：新しいアプリコード版に更新し、英語UI辞書をPWAキャッシュに含める。旧キャッシュは既存のactivate制御で整理。
- `styles.css`：プレビュー限定の警告を画面に常時表示し、科学説明・法文書の未翻訳を案内。

## 3. 画面設計根拠と制約
- 日本語は初期状態として完全に維持する（トップナビ、8段階の初回案内、20画面、結果3タブ、研究上の注意）。
- 英語モードでは主要操作が英語化されるが、未翻訳文面は原文のまま保持。自動翻訳で研究の適用条件・ROF-Jの0と未回答・GPS位置共有・同意文言を誤変換しない。
- ユーザー入力や保存済みIDを意図的に翻訳・変更しない。辞書にないUI文面も日本語の原文を維持。翻訳はDOM表示層に限定する。
- 日本語の同意記録と英語UIの選択は別物。**言語選択は同意として扱わない。** 同意画面/法的文書の正式英訳がない間は初回のEnglishカードを選択可能にしない。
- `document.documentElement.lang` を表示モードに合わせ、公式法文書のモーダルは日本語属性を持つ。英語未訳文の個別読み上げ品質は別途監査が必要。
- 共有PNG・PDF・書き出しに残る日本語は未完成として明記し、英語版の正式完成宣言は行わない。

## 5. 英語正式完成へ残る仕事（未PASS）
1. 全20画面と8段階初回案内の利用者向け長文を、意味・出典・限定条件を維持して逐語レベルで日英対訳レビューする。日時・速度・単位などのロケール固有表現も明示的に定義する。
2. GPS権限・停止/再開、欠測・保存失敗、バックアップ破損・復元前確認、共有・画像・PDFの注意文を全状態で英訳・校正する。
3. 法的文書の適用範囲と日英の意味差を専門的に検証した完成版を用意し、初回言語選択から本人が理解して同意できるようにする。英語正式版がないうちに日本語同意を英語同意と呼ばない。
4. 320/390/768/1024/1440pxと200%文字拡大、Chromium/WebKit、文字切れ・フォーカス・読み上げ・オフライン遷移を全画面で検証。物理iOS/Androidは別評価。
5. 正式Currentの無断上書きを行わず、研究原著の独立計算・29成立条件の正式審査・本人の自己理解への実証的効果を混同しない。

**研究上の限定**：RunLoadの参考値は各部位自身の文献内基準100であり身体組織負荷・診断・傷害リスクの測定や予測ではない。ROF-Jは本人申告で0は有効回答、未回答とは異なる。英語プレビューもこの区別を緩めない。

## 6. 第2段階：主要画面の説明・注意文と入力ガイドの英訳（2026-11-11）

### 今回の変更と設計根拠

英語プレビューをラベル中心の初期版から、次の**固定文言の説明・注意・検証ガイド**へ拡張した。翻訳の安全性を確保するため「日本語原文→英語文」を一対一で監査できる独立したモジュールに分離する。

| ファイル | 対象と追加数（日本語キー） | 意味・根拠の保持 |
|---|---|---|
| `ui/englishRecordHistoryCopy.js` | 記録、コース/勾配/路面、保存前確認、履歴の空状態・保存領域の欠測（約140語句） | 必須入力、本人の原本と保存済み履歴の区別、コース編集が過去の走行を変更しない |
| `ui/englishResultCopy.js` | 12部位、文献適用条件、ROF-Jの回答時刻、二記録比較と限界（約90語句） | 各部位の文献内基準100、診断非該当、回答0と未回答の区別、時系列/因果を推定しない |
| `ui/englishGpsExplorationCopy.js` | GPS測位・保存の任意性、測定誤差、記録未保存時、探究の関連表示と注意（約102語句） | GPS詳細軌跡は選択制、速度から活動種別を自動推定しない、強調表示は危険度を示さない |
| `ui/englishSettingsCopy.js` | 利用者設定、位置権限、保存/競合時のエラー・説明（約43語句） | この画面ではOSの位置権限を変更できない、競合時は上書きしない、プロフィールは任意 |

`ui/englishUi.js` は4モジュールを固定語句辞書へ接続し、画面の再描画やShadow DOMに追従する。入力欄の **placeholder／aria-label／title** だけを翻訳する際も、`input.value`・`textarea.value` と自由記述の本文は変更しない。本人入力の記録名、メモ、ID、日付の数値、ROF-Jの値を文字列置換していない。

`index.html` / `sw.js` は `20261111-i18n-copypass2-v1` に更新し、上記4ファイルをPWAプリキャッシュに追加。通信なしの表示でも辞書の欠落が起きないよう、既存の正本キャッシュ検査を維持した。通常の利用に翻訳API・追加ネットワーク送信は不要。
