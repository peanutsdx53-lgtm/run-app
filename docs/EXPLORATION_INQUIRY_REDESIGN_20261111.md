# RunLoad｜探究画面・選んだ分野の一体型レイアウト改修（2026-11-11）

## 決定事項
利用者から「疑問形の連続表示を避ける」「学習は知識の理解、探究は本人の記録・感覚・経験の吟味として差別化」「気温・天候などの専用問いを画面上部へ挿入する方式は、レイアウト確定後に撤去」と依頼・承認された。

## 機能設計根拠
RunLoadの自己理解は、本人が走行記録・感覚の意味と限界を自らの状況・過去経験に照らして吟味し、暫定的な気づきや疑問を形成・更新する過程。よって、探究を学習教材の反復・追加問題・正解判定にしない。質問は各28テーマにつき冒頭1問とし、後続は「記録を手がかりにする」「記録と感覚を照らし合わせる」「気づきを残す」の行為を示す見出しとする。記録の有無でアクセスを制限せず、本人の記述保存は本人操作に限定。

## 画面設計根拠
「選んだ分野」のカードは1枚とし、内部を区切り線で構成。冒頭の問い（1つ）、本人が確認する記録またはテーマ固有の操作、限界と出典の開閉情報、任意メモを縦に配置。10件の根拠付き知識本文は「参考知識と研究の出典」に折りたたみ、18件の観察ガイドは原著審査未完了を明示したまま同じ構造に配置する。

## 6種類の専用問いの扱い
現行の上部挿入処理を廃止する：T02疲労感、T03精神面、T04身体記述、T05気温・天候、T06生活コンディション、T08過去比較。専用の記録確認・出所・安全限界・後日申告確認の操作は、対象テーマの「記録を手がかりにする」領域にのみ配置し、重複する見出し・二重の問い・専用メモ操作を省く。ほかのテーマを表示中・テーマ一覧の表示中に専用パネルを差し込まない。

## 維持条件・限界
- 保存済み走行の明示的選択、GPSの後日追記や精神面回答の非自動開示、出所・未回答・撤回・読取エラーの区別、比較対象の本人選択、同一記録のリンクを維持する。
- 医学的診断、原因推定、研究の一般化、文献12部位の実測値への置換、個別トレーニング処方を行わない。
- 本人メモ・記録・科学式・保存キー、正式Currentは変更しない。日本語に対応する英語表示を追加し、学術的限界を削除しない。
- テストは全28テーマの出力・1つの冒頭問い・3区分・出所条件・英語対応・320/390px・WebKit/Chromium・オフラインを確認。実機Safari上の長文表示と操作は別途受入確認が必要。ブラウザPASSは研究効果・実機PASSを意味しない。
