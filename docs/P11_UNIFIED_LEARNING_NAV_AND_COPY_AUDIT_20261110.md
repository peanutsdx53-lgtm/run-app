# P11｜学習表示・共通ナビ・禁止語の厳格監査（2026-11-10）

## 変更承認・実行境界
- 利用者が明示した例外により、今回のみ main へ直接コミット。新規ブランチは作らない。
- ユーザー指摘：学習画面だけ明色となり、ホーム・探究・設定と統一されていない。学習/探究のトップに不要な下向き矢印とメニューがある。スマホ下部ナビに設定を戻す。
- **ホームのクイックアクセス**のコース設計・シミュレーション・相談共有を唯一の既存入口として保持。設定画面への移設や重複追加は一切しない。

## 機能根拠（WHAT）
- 学習は一般知識と架空例であり、効果実証や個人の身体測定とは異なる。4教材の内容・出典・出所と申告の区別・正誤判定を維持。
- 禁止表記の監査は学習の利用者向け文章（一覧、主教材3件、補助教材、各章、復習・進捗）に限定した検索と描画後の二層検査。JavaScript識別子・保存キー・キャッシュ名はUIに表示されない内部実装のため、互換性を優先し変更しない。

## 画面根拠（HOW）
- 学習のヘッダー、教材カード、章カード、復習、進捗、選択肢を**ホーム・探究と共通の濃紺・青緑**へ統一。別色の明色テーマを最終カスケードで上書き。
- 不要なヘッダーの「メニュー」と下向きインストールアイコンをDOMから除去。空のtopbarは互換性のため不可視で保持。
- スマホナビを「ホーム・記録・履歴・探究・学習・設定」の6項目に変更（320pxから）。設定は下部から直接開ける。PC側の既存設定リンクは保持。
- アプリインストール方法の案内は既存の**設定**内に保持。ホームの3クイックアクセスは変更しない。

## 学習内の禁止表記・7箇所と置換の判断
1. 補助教材：尺度原著とは別の保存仕様であることを「本アプリ独自のデータ設計」に変更。
2. 補助教材：原本と後日追記の境界を「本アプリでは」に変更。
3. 補助教材：介入効果が未検証である限界を「この教材の教育効果」に変更。
4. 動作教材：アプリ操作ではなく運動の一般知識である説明を「この教材はアプリの操作方法を説明するものではありません」に変更。
5. 動作教材：本人への直接計測でないことを「本人の脚を直接測定した情報ではない」に変更。
6. 疲労教材：RPEを記録する機能を誤解させないため「本アプリが本人のRPEを記録しているという意味ではありません」に変更。
7. 疲労教材：対象集団の限界を「本アプリの利用者を対象とした介入試験ではありません」に変更。
- 確認：文献名、研究対象・条件、ROF-J/RPE区分、保存と自己申告の境界は保持。

## 試験と受入の限界
- Nodeソース/HTML生成監査：4教材と一覧の可視本文に `/runload/i` を禁止。
- Playwright Chromium/WebKit、320/390/768/1440px：描画された全教材の章を展開後に禁止語を検査、メニュー/矢印不在、6リンク、ホーム3機能保持、設定への不当な移設なし、濃紺ヘッダー、横方向のはみ出しを確認。390pxルート文字200%も検査。
- オフラインPWAの更新キャッシュを変更、CSS新規ファイルを予備キャッシュへ追加。既存の正本データ、科学計算、正式Current、旧29成立条件は変更しない。
- CI/デプロイとiPhoneでの最終目視は独立して報告。実機合格・学習効果・自己理解改善は自動テストだけで証明しない。
