# RunLoad 学習・探究画面の冗長情報整理（2026-11-11）

## 操作対象・証拠
iPhone実機の学習単元末尾、探究分野選択・テーマ表示画面に関する指摘。日本語・英語の表示、画面操作、オフラインキャッシュを更新。正式Currentは変更しない。

## 変更と画面設計根拠
1. 学習：ペース教材の「関連する補助教材 · 任意」「RELATED · 違う観点の教材」の重複カードを**コードから削除**。身体動作・疲労教材・補助教材の末尾に並ぶ他単元への重複リンクも削除。学習一覧への戻り、各単元の説明・研究条件・4問の復習、本人が明示的に「探究へ進む」「履歴から選ぶ」導線は保持。
2. 探究：コンステレーション下の既存テーマへのジャンプボタンと専用処理・CSSを削除。選択した分野の非記録時の定型説明、および古い「どれから読んでみる？」「Nテーマ・横に動かして選ぶ」見出しを削除。
3. 探究：選択した分野のテーマ欄に「テーマを切り替える」、前／次ボタン、選択位置（例：1 / 4）、横スワイプまたは矢印の説明を設置。ボタンは最初・最後で disabled。既存のテーマタップ・横スクロールと選択中テーマへのフォーカスを保持。44px以上のボタン、キーボードフォーカス、英語ラベルを確認対象とする。
4. 探究：知識欄の「まずは知ってみよう」、根拠がないときに重複する坂道割合の定型文、ふり返り欄の自明な説明文を削除。坂道の構成比が有効に入力されているときの数値・GPSでない等の意味と限界は引き続き表示。学習の根拠と適用条件、個人データの自動連結不可という制約は保持。

## 機能設計根拠と限界
初心者が記録・感覚を吟味し、暫定的な問いを作るため、操作に必須な案内と科学的限界を分ける。冗長なナビゲーションカードや定型文の削除は研究効果の実証ではない。記録がない場合の欠測を0%へ読み替えず、計算値が存在するときにだけ表示する。学習から探究へ移る際は本人の走行情報を自動選択しない。元の回答・記録・メモ・文献参考値を変更しない。

## 正常系・反例の受入条件
- 学習4教材の本文、研究出典、復習4問、探究リンク・履歴リンクを残し、重複した他単元への案内は出さない。
- 探究の7分野からテーマ表示ができる。テーマ2件以上で前後ボタンが選択を変更し、位置が更新される。先頭の前ボタン・末尾の次ボタンは無効化され、1テーマでも操作できる。横スクロールと個別選択が使える。
- 記録0件で仮の坂道割合を描かない。構成比が有効なときは本人の入力とGPS測定を混同しない。自由記述は明示的操作だけで保存。
- 320/390px、200%文字拡大、Chromium/WebKit、英語表示、オフライン更新を確認対象とする。実iOS Safariでの押下挙動は別途実機確認が必要。
