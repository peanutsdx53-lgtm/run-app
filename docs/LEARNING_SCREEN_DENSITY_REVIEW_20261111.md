# RunLoad 学習画面・表示密度改修 2026-11-11

## 対象・変更
- ユーザー提供のiPhone実機画像に基づき、学習一覧の導入カードと学習記録カード、および主教材3件・補助教材1件の単元冒頭の導入/学習記録カードを削除。各教材は単元名の平文見出しと章本文を残す。
- 「？」は学習の目的と操作方法（教材を選ぶ、章を開く、復習する、補助教材を参照する）の簡潔な説明へ変更。
- 復習の1問表示・ページ送り・「すべての問を表示」の生成処理を削除し、各教材の4問を常時表示。未回答も回答可能。解答・理由・関連章への戻りは保持。
- 学習済みチェックのUI生成と保存ロジックを削除。過去のチェック情報を持つ端末の全データ削除互換だけ維持。既存の走行記録・探究記録・科学計算・正式Currentは変更しない。
- 補助教材を含む章内の「理由を確認」「ヒントを見る」ボタンの既定/hover/active/focusに、暗背景と十分に明るい文字色を指定。iOSの標準ボタン背景を抑制する。
- 英語版ヘルプの新規日本語表現に対応する明示的英訳を追加。日本語教材の科学的根拠・原著リンク・例題・正解番号は変更しない。

## 研究・機能根拠
一般知識の学習は本人の医学的診断や自己理解向上を実証するものではない。研究上必要な各教材内の対象・測定条件・適用限界、欠測や出所の区別を保持し、説明の重複と進捗/採点誤認を招くカードを撤去する。研究効果を推論しない。

## 画面根拠・受入観点
冒頭に不要な大きいカードを重ねず、主教材の学習項目にすぐ到達できる。章の開閉は既存方式を維持し、復習の開章時は全問が見える。小画面320pxと英語長文、200%文字拡大で横はみ出しの有無、4教材の復習、ボタンの押下配色をブラウザ・実機で照合する。Chromium/WebKitは実iOS Safariの代替ではない。

## 更新対象と境界
ui/learningExperience.js, learningPresentation.js, learning{Origin,Motion,Fatigue}Lesson.js, learningExperience.css, unifiedLearningShell.css, englishCurriculumCopy.js, app.js, index.html, sw.js および関連回帰試験。mainに直接反映するという今回の明示指示に限定。正式Currentの上書きは行わない。
