# RunLoad P10 — 学習画面実機フィードバック対応・設計/検証境界（2026-11-10）

## 観測の起点
iPhone実機で確認した学習画面の2枚のスクリーンショット。濃紺ヒーロー/カードとアプリの他画面との不統一、7つの近接した目次ボタン、縦長の講義と復習、設問の番号・本文が重なった見出し、進捗感の欠如を指摘。実機画像は**問題発見の証拠**であり、修正後の実機PASSではない。

## 機能設計根拠（WHAT）
- 任意の一般知識教材は、本人の走行記録・医学的推定・自己理解の実証と独立。
- 同じ平均値で異なる区間配分があり得ること、参考値の文献適用条件・限界、0と未回答の区別は不変更。
- 進捗は「利用者が明示的に学習済みとして記録した教材数」（主教材3件＋補助教材1件）。理解や効果が確認されたことは意味しない。学習閲覧時には自動で学習済みにしない。
- 進捗は独立した localStorage キー \`runload-v2-learning-checklist-v1\` のみに保存。走行の正本、GPS、精神面、自己記述、復習の正誤・回答内容は保存・変更しない。
- 保存失敗/破損時には学習記録を「取得不能」として扱い、完了を捏造しない。復習は未回答のまま進めることも可能。学習済みチェックは走行バックアップに含まれないと明記し、全データ削除では削除対象にする。

## 画面設計根拠（HOW）
- 他画面と親和的なライトグレー/淡い青緑のヘッダー、白いカード、控えめな枠・影。主CTAのみ落ち着いた青緑を使う。グローバルナビの項目数・リンク・状態は維持。
- 教材一覧の先頭に4件分の学習済み記録状況を表示。各教材カードに記録状態。教材に入ると明示操作ボタンで学習済み/未完了を切替。
- 講義内の目次（最大8ボタン）は既定で畳み、グループ「知る」「試す」「復習・探究」に整理。元のボタンノードを移動するためイベントハンドラと画面内ジャンプを維持。
- 長い目標説明は「この教材で学ぶこと」の折りたたみ内へ。各章も見出しを保ったまま開閉可能にし、必要な章と復習・探究の導線を既定表示する。「すべての章を開く」も残す。詳細本文は省略しない。
- 復習設問は1問ずつ表示し、「すべての問を表示」へ切り替え可能。番号と設問本文を独立した表示要素・アクセシブルなラベルに分離。前/次ナビゲーションを提供。
- 320・390・768・1440px、Chromium/WebKit、390pxの200%ブラウザルート文字拡大を確認し、レイアウト超過を認めない。

## 限界と運用
- 既存教材の学術内容、数式、正解、解説、文献の適用範囲を変更しない。
- この改修で自己理解・学習効果の向上を示すことはできない。
- iOS/Android実機の操作・OS拡大・インストールPWA・GPS・公開反映は別の受入。画面テスト成功だけで正式承認としない。
- P9公開済みmainと独立した feature ブランチ/Draft PR上で実施。正式Current・旧29成立条件原本への書き込みなし。
- 既存のP9認証境界・オフライン再訪の試験を維持し、P10用に追加したJS/CSSをService Workerに明示的にキャッシュする。
