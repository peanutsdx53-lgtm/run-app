# 初回画面の英語表示と英語版準備（2026-11-10）

## この工程の変更範囲
- 最初の「表示言語」画面の **English選択肢** の字幕、選択不可表示、アクセシビリティ用説明を英語に統一した。英語カード全体に `lang="en"` を付けて読み上げ言語を指定。
- 表示は `English / Coming soon / Not available`。英語版は未実装のため選択不可を維持。日本語の他の初回ガイド・利用規約・プライバシー・通常画面は変更しない。
- オフラインキャッシュ名を更新し、初回ガイドの新しいHTML生成コードをインストール後のキャッシュに再取得する。既存の起動高速化処理は変更しない。
- Node表示契約とChromium/WebKit初回ガイド試験の英語選択肢検証を追加。UIの他言語化や保存仕様の変更を証明するものではない。

## 今後の英語版実装の前提（未実装）
1. UIモジュールを横断して利用者向けテキストの所在を棚卸しする。画面文字列、aria/alt、通知、検証エラー、ヘルプ、利用規約・プライバシー、PWAメタデータと印刷・PDF・共有出力も対象にする。
2. 日本語を既定のまま、翻訳キーと共通辞書、言語選択状態、未翻訳検出、言語別の数値・日時・単位表示を独立した層にする。既存の業務ロジックと文字列を混同しない。
3. 記録・研究計算・科学的前提・履歴比較・GPS・同意状態の正本や既存ストレージキーは変更しない。言語切替に伴う記録破損、共有誤訳、根拠の言い換えを回帰試験で防ぐ。
4. 英語の利用規約とプライバシーポリシーは単純な機械置換で公開せず、内容と適用範囲を確認した完成版で提供する。
5. 日本語・英語それぞれで初回8ステップ、主要20画面、320px/390px/デスクトップ、オフライン復帰、キーボード・スクリーンリーダー、エラー経路を実ブラウザで確認する。
6. 将来の公開先変更に合わせて、リポジトリ固有URLや開発・研究上の内部名を画面に再導入しない。

## 本工程では検証できないこと
英語版全画面の動作、英訳の妥当性、全端末実機による表示品質は今回の受入対象外。英語版の提供可否は整理後の別工程で判断する。
