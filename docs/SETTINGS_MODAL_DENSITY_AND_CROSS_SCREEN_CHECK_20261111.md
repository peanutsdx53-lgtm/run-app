# RunLoad 設定画面・共通ダイアログ表示監査（2026-11-11）

## 実機で確認された問題
iPhoneの設定画面で、日本語設定中に英文の法的補足が常時表示された。バックアップ作成・削除では、長文の注意書きが操作フォームを画面下へ押し下げていた。利用規約・プライバシーポリシーのモーダルで上部見出しが見切れ、閉じるボタンの形が他画面と不統一だった。

## 画面設計上の判断
- 言語切替直下の英文補足を完全削除する。日本語規約・方針の本文および英語参考訳そのものは維持。
- バックアップ作成・復元・データ削除では「何をするか」「重要な安全上の注意」「実行操作」を先に配置し、細かなデータ範囲・技術的制約を native details に移す。警告を削除したり、同意手順・安全確認を省略しない。
- 法的文書ダイアログをアプリのスクロール領域から切り離した body 直下に配置。iOSの安全領域を踏まえて高さを調整する。見出しと正方形44pxの×ボタン、下部の戻る操作は固定し、本文のみ内部スクロール。
- 開いた直後に本文へフォーカスして不意にスクロールさせず、閉じるボタンへ preventScroll でフォーカスする。閉じたら起動元へ戻し、Escape と Tab 循環を用意する。
- この問題は**全画面共通の将来の監査項目**。同じく長文や拡大文字を持つ、初回ガイド、探究、確認、記録、削除確認、ホーム詳細等のモーダルでも、上部・閉じる操作・下部が欠けないかを検証する。

## 機能根拠・安全上の境界
JSONバックアップは外部へ自動送信せず、暗号化されない。個人の生活・身体に関する情報、GPSを選んだ場合の経路・位置情報の注意は初期表示のまま保持する。復元の一部失敗リスク、競合防止、データ削除の不可逆性、削除されないダウンロード済みファイルやキャッシュ、確認チェックと「削除」入力の2段階条件は残す。データ形式、保存キー、削除対象、同意記録の取扱いは変更しない。

## 検証
ユーザー提供iPhoneスクリーンショット3枚と現行mainのソースから問題を特定。320/390pxおよびデスクトップ、200%表示、Chromium/WebKitで、画面上端からの見出し・×・下端操作の収まり、本文スクロール、バックアップ・削除の画面撮影、既存データ安全性と英訳を自動確認する。
実機Safariでの最終判定は別途実機確認が必要であり、ブラウザエミュレーションのPASSを実機PASSと記録しない。正式Currentへの書込みはしない。
