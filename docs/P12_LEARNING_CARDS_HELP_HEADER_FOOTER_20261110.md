1. **ホーム**：画面ガイドの開閉状態、文章3段落と注意書き、閉じる操作、編集機能を保持。既存ガイドを「？」で起動し、編集→「？」の順とする。
2. **学習**：学習済みは本人の明示操作でのみ記録する既存契約を保持。3教材・補助教材の本文、リンク、復習、学術的限定事項は保持。画面下部のガイド（学習順路と任意性、仮想例の区別を含む）を上部へ移し、重複した下部表示は廃止。主教材・補助教材の表示順は不変更。

4. **探究**：「ふり返り」は上部から外し、下部に独立した案内カードと保存件数つきボタンで置く。ボタンの既存 `memories` action、保存・修正・削除・元記録とのリンクは不変更。ノート内の移動説明を「画面下部」に整合。ヘッダーには「？」のみ。
