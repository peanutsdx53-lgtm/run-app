# RunLoad｜ホーム編集即時保存・ボタン表示横断監査・文言と詳細画面の調整（2026-11-11）

## 利用者からの報告
iPhoneのホーム編集操作で、追加などのボタンを押すと背景だけ白くなり文字が読みにくい。最新の走行・実績・記録の移り変わりから重複した説明を削除したい。コンディションと実績の詳細見出しを利用規約・プライバシーポリシーのダイアログへ揃えたい。ホーム編集は操作ごとに自動保存し、独立した「変更を保存」「キャンセル」は廃止したい。

## 機能設計根拠
表示設定は `runload-v2-home-dashboard-layout-v1` に限定し、追加／非表示、上下移動、サイズ変更、ドラッグ確定、初期配置への復帰時に即時永続化する。編集終了は表示切替のみ。読取失敗、形式破損、別タブの新規変更は上書きせず、利用者へ理由を通知して確定済みレイアウトを保持する。走行・GPS・文献参考値・メモ・同意の正本を編集しない。

## 画面設計根拠
`styles.css` の `.widget-edit-actions button:hover:not(:disabled)` が淡い背景を設定し、`homeExperience.css` の淡色文字指定より優先されていた。iOS Safariではタップ後もhoverが残るため、Home編集のボタンの通常／hover／active／focusで暗色背景と高コントラスト文字を明示し、編集終了、初期配置ボタン、詳細ダイアログの操作も対象に加えた。

最新走行の補足バッジ、実績カードの進捗と集計方法の重複文字、距離推移の長文を削除。実績は保存済み手入力走行のみ、距離推移は各走行単位で同一日の複数件を別表示し、長さは表示内最大距離の比率とする。未記録日はゼロではない。計算方法・欠測区別・健康診断非該当の注意は実装と必要な詳細画面に残す。

コンディション・実績の詳細を共通の固定タイトルバー（44px閉じるボタン）と内部スクロール本文に変更。フォームの明示的保存と削除確認は維持。

## 検証と残る限界
`homeDashboardLayout.test.mjs` の即時保存／競合防止、`homeExperience.test.mjs` の削除文言・データ保持、`s02HomeGuideBrowser.mjs` のhover、編集／再読込、ダイアログレイアウトをChrome/WebKit・320/390/768/1440pxで確認する。対象SHAのCI終了前はPASS認定しない。物理iPhone Safariでの最終確認、研究29成立条件の正式認定、原著再計算は本変更で行わない。正式Currentへの変更なし。

2026-11-11: 旧「手動保存」の英語案内を新しい全文に対応させ、「編集を終了」を明示的に英訳した。短句だけの辞書登録では複合文章を翻訳できないため、全文を単一の翻訳キーとして登録する。「初期配置に戻す」を320pxでも全幅の44px操作として確保し、Chromium/WebKitの幅と押下色試験を拡張。PWAキャッシュを 20261111-home-autosave-refine-v2 に更新した。
